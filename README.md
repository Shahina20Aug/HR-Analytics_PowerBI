HR Analytics – Excel Project
📌 Project Overview

This project focuses on analyzing Human Resources (HR) data using Microsoft Excel. The objective is to understand employee demographics, workforce distribution, employee performance, salary trends, and employee attrition.

The project uses Excel features such as data cleaning, formulas, Pivot Tables, Pivot Charts, and dashboards to transform raw HR data into meaningful business insights.

🎯 Objectives

Analyze overall employee workforce data.

Understand employee demographics and department distribution.

Analyze employee attrition and identify possible trends.

Compare employee salaries across departments and job roles.

Analyze employee performance.

Understand employee experience and tenure.

Build an interactive HR Analytics dashboard.

Provide insights that can support HR decision-making.
